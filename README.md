# 横スクロールシューティング (shooter)

スマホのブラウザで完結して遊べる、横スクロール型のシューティングミニゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 画面をタップ（またはマウスクリック、スペースキー / Enterキー）してスタート
3. 画面下部の十字ボタン（▲▼◀▶）、または矢印キー / WASDキーで自機を上下・前後に操作します（前後は画面左側の範囲内で移動できます）。自機の艦尾からは常に小さな気泡が漏れています
4. 画面下部には起伏のある海底があります。平らな場所も山もあり、自機・敵・弾ともに衝突すると消えたり（敵・弾）ダメージを受けたり（自機）します
5. 弾は自動で発射されます。敵を避けつつ倒してスコアを稼いでください
   - 敵は種類ごとに見た目と動きが異なります。**ステージが進むほど新しい敵が混ざります**
     - **ピラニア**（全ステージ）: 直進。3匹の群れで前後上下に揺れながら出現
     - **毒クラゲ**（全ステージ）: サインカーブ移動
     - **ウニ**（全ステージ）: 自機狙いのとげを飛ばす。発射直前は目が赤く光ります
     - **カジキ**（ステージ2以降）: 画面右端で狙いを定めて光ったあと、自機めがけて高速で突進してきます
     - **ウツボ**（ステージ2以降）: 海底の巣穴に潜んで待ち伏せ、近づくと飛び出して噛みついてきます
     - **フグ**（ステージ3）: 硬く、ダメージを受けるほど膨らみます。倒すと全方位にトゲを撒き散らすので倒す位置に注意
     - **タコ**（ステージ3）: 墨を吐きます。墨はダメージこそないものの視界を奪います
     - **チョウチンアンコウ**（潜航パート）: 普段は光る誘引突起だけが見え、近づくと本体を現して襲いかかってきます
6. 敵を14体倒すとステージごとの障害が出現します
   - **ステージ1**: 火山が出現し、赤いマグマが不規則な間隔・方向で飛んできます
   - **ステージ2**: 漏斗状の渦が画面右から流れてきます。渦に入ると操作を奪われ、渦の内壁を回りながら底へ引きずり込まれます（渦が画面外へ流れ去ると解放されます）
   - **ステージ3**: 海底が途切れて大穴（THE ABYSS）が現れ、画面が穴の上に来ると **縦スクロールの潜航パートに切り替わります**（後述）
7. 敵を倒すと確率でアイテムをドロップします。取得すると効果が発動します（時間制限なし。弾の種類は別のアイテムを取るかリスタートするまで持続）
   - **3-WAY**（緑）: 斜め方向にも弾が出る3方向弾になる
   - **HOMING**（ピンク）: 近くの敵に向かって曲がりながら追尾する誘導弾になる（追尾できるのは一定距離内の敵だけで、旋回もゆるやかなため大きく外れた敵には当たりません）
   - **PIERCE**（黄）: 敵を貫通して進み続ける弾になる
   - **WIDE**（水色）: 弾が大きくなり当たり判定が広くなる
   - **RAPID**（オレンジ）: 弾の発射間隔が短くなる
   - **SPEED**（紫）: 自機の移動速度が上がる
   - **SHIELD**（緑青）: 被弾を2回まで肩代わりするバリアを張る（発動中は自機を囲む発光リングが表示され、残り2回は二重の太いリング、残り1回は細いリングになる。2回使い切ると外側へ広がって消える）
   - **HEAL**（赤紫）: ライフが1回復する（上限5）
   - **ESCORT**（黄緑）: 味方の小型潜水艦が来て一緒に戦ってくれる（最大2機。通常時は自機の上下、潜航中は左右に並んで自動で射撃します。被弾すると失われるので自機の盾にもなります）
8. 敵を30体倒すとそのステージのボスが画面後方から現れます。ボスは時々自機の近くまで突進してきます
9. **ステージ3の潜航パート**: 大穴に差しかかると横スクロールが止まり、縦スクロールで海底の縦穴を潜っていきます
   - 左右が岩壁になり、ぶつかるとダメージを受けます。自機は画面の左右いっぱいに動けます
   - 弾は真下に向かって発射され、下から浮上してくる敵と撃ち合います
   - 潜るほど画面が暗くなり、HUDに現在の深度（DEPTH）が表示されます
   - 深度2000mまで潜ると縦穴を抜けて海底に到達し、**再び横スクロールに戻ります**（「SEA FLOOR」バナー）。深海なので画面は暗いままです
   - 横スクロールに戻って少し進むと、ボス（ダイオウイカ）が通常どおり画面後方から現れます
10. 全3ステージあり、ボスを倒すごとに次のステージへ進みます（サメ → カニ → ダイオウイカ）。ステージが切り替わると「STAGE X」のバナーが表示され、敵の撃破数・火山や渦・潜航の進行もステージごとにリセットされます。最終ステージのボスを倒すと全クリアです
11. ライフが0になっても **コンティニューが2回まで** できます。画面タップで再開でき、残り回数はHUDに表示されます
    - **ボス戦で力尽きた場合**: そのボス戦から再開します（ボスのHPは全回復）
    - **それ以外で力尽きた場合**: そのステージの最初から再開します
    - コンティニューを使い切ってライフが0になるとゲームオーバー。画面タップで最初からリスタートできます
    - 再開時はライフが3に戻り、アイテムの効果（弾種・護衛機など）は失われます。スコアは引き継がれます
12. プレイ中は画面右上のボタン（PキーまたはEscキーでも可）でポーズできます。ポーズ中は敵や弾の動きが止まり、同じボタンで再開、RESTARTボタンで最初からやり直せます

## デバッグモード

URLに `?debug=1` を付けて開くと、開発用のデバッグモードが有効になります（付けない通常プレイには一切影響しません）。

画面下部の操作バー右側に以下のボタンが表示されます。

- **STAGE ▶** — 次のステージへ即座に進む（最終ステージなら全クリア扱い）
- **BOSS** — 現在のステージのボスをその場で出現させる
- **MUTEKI** — 無敵のON/OFF切り替え（ONの間は被弾してもライフが減らない）

PCではキーボードでも操作できます: `N` = ステージスキップ、`B` = ボス出現、`I` = 無敵切り替え。

## 構成

- `index.html` — キャンバスとビューポート設定
- `game.js` — ゲームロジック一式（入力・敵・弾・当たり判定・描画）
- `version.js` — バージョン番号定義。PRの作成・更新のたびに GitHub Actions（`.github/workflows/version-bump.yml`）が自動で書き換える自動生成ファイルなので、手動編集しない

ビルド不要。`index.html` を開くだけで動作します。
