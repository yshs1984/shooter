# DEEP DIVER (shooter)

スマホのブラウザで完結して遊べる、横スクロール型のシューティングミニゲームです。潜水艦を操作して深海の生物と戦い、終盤は海底の大穴を潜っていきます。

## 遊び方

1. `index.html` をブラウザで開く
2. 画面をタップ（またはマウスクリック、スペースキー / Enterキー）してスタート
3. 画面下部の十字ボタン（▲▼◀▶）、または矢印キー / WASDキーで自機を上下・前後に操作します（画面内であれば右端まで前進できます。前に出るほど敵の出現位置に近づき危険です）。自機の艦尾からは常に小さな気泡が漏れています
4. 画面下部には起伏のある海底があります。平らな場所も山もあり、自機・敵・弾ともに衝突すると消えたり（敵・弾）ダメージを受けたり（自機）します
5. 弾は自動で発射されます。敵を避けつつ倒してスコアを稼いでください
   - 敵は種類ごとに見た目と動きが異なります。**ステージが進むほど新しい敵が混ざります**
     - **ピラニア**（全ステージ）: 直進。3匹の群れで前後上下に揺れながら出現
     - **毒クラゲ**（全ステージ）: サインカーブ移動
     - **ウニ**（全ステージ）: 自機狙いのとげを飛ばす。発射直前は目が赤く光ります
     - **カジキ**（ステージ2以降）: 画面右端で狙いを定めて光ったあと、自機めがけて高速で突進してきます
     - **ウツボ**（ステージ2以降）: 海底の巣穴に潜んで待ち伏せ、近づくと飛び出して噛みついてきます
     - **フグ**（ステージ3以降）: 硬く、ダメージを受けるほど膨らみます。倒すと全方位にトゲを撒き散らすので倒す位置に注意
     - **タコ**（ステージ3以降）: 墨を吐きます。墨はダメージこそないものの視界を奪います
     - **チョウチンアンコウ**（潜航パート）: 普段は光る誘引突起だけが見え、近づくと本体を現して襲いかかってきます
6. 敵を14体倒すとステージごとの障害が出現します
   - **ステージ1**: 海底の山が噴火を始めます。火山は地形の一部なので **スクロールに合わせて次々に流れてきます**。山頂の火口から赤いマグマが不規則な間隔・方向で飛んできます
   - **ステージ2**: 漏斗状の渦が画面右から **次々と流れてきます**（大きさ・深さ・高さ・速さはばらばらで、同時に複数出ることもあります）。渦に入ると操作を奪われ、渦の内壁を回りながら底へ引きずり込まれます（渦が画面外へ流れ去ると解放されます）
   - **ステージ3**: 海底の山に沈没船の残骸が刺さっており、**隙間を縫って進む**必要があります。まれに船体からデブリが剥がれ落ち、ゆっくり漂います
   - **ステージ4**: 海底が途切れて大穴（THE ABYSS）が現れ、画面が穴の上に来ると **縦スクロールの潜航パートに切り替わります**（後述）
   - **ステージ5**: ステージ4と同じく大穴から潜航パートへ切り替わり、そのまま深海の続きとしてボス連戦（後述）に入ります
7. 敵を倒すと確率でアイテムをドロップします。取得すると効果が発動します（時間制限なし。弾の種類は別のアイテムを取るかリスタートするまで持続）
   - **3-WAY**（緑）: 斜め方向にも弾が出る3方向弾になる
   - **HOMING**（ピンク）: 近くの敵に向かって曲がりながら追尾する誘導弾になる（追尾できるのは一定距離内の敵だけで、旋回もゆるやかなため大きく外れた敵には当たりません）
   - **PIERCE**（黄）: 敵を貫通して進み続ける弾になる
   - **WIDE**（水色）: 弾が大きくなり当たり判定が広くなる（弾速・威力は通常弾と同じ）
   - **TORPEDO**（薄橙）: 魚雷を撃つ。**1発で4ダメージ**と最も一撃が重いが、発射間隔は2倍に伸びる。硬い相手向け
   - **RAPID**（オレンジ）: 弾の発射間隔が短くなる
   - **SPEED**（紫）: 自機の移動速度が上がる
   - **SHIELD**（緑青）: 被弾を2回まで肩代わりするバリアを張る（発動中は自機を囲む発光リングが表示され、残り2回は二重の太いリング、残り1回は細いリングになる。2回使い切ると外側へ広がって消える）
   - **HEAL**（赤紫）: ライフが1回復する（上限5）
   - **ESCORT**（黄緑）: 味方の小型潜水艦が来て一緒に戦ってくれる（最大2機。通常時は自機の上下、潜航中は左右に並んで自動で射撃します。被弾すると失われるので自機の盾にもなります）
8. **ステージ3では、敵を22体倒すと道中に中ボス「半魚人」が現れます**（「MID BOSS」バナー）
   - 銛を構えてから投げ、ワイヤーで手元へ引き戻してきます。**行きだけでなく戻ってくる銛にも当たり判定がある**うえ、投げたあとも半魚人自身が泳いで動くため戻り道の軌道がずれます。構えている間は目が赤く光るので、そこを見て避ける位置を決めます
   - 銛は自機の位置を通り越すところまで飛んでくるので、その場に留まっていても避けられません
   - 倒すと**必ずアイテムを1つ落とします**。倒さずに耐えることもできますが、その場合アイテムは手に入りません
   - 中ボスで力尽きた場合はステージの最初からやり直しになります（ボス戦のようなチェックポイントにはなりません）
9. 敵を30体倒すとそのステージのボスが画面後方から現れます。ボスは時々自機の近くまで突進してきます
   - **ボス戦中も通常の敵が少しずつ出現し、アイテムを落とします**（ドロップ率も上がります）。コンティニュー直後でも装備を立て直せます。ただし飛び道具で難易度が跳ね上がらないよう、**ウニはボス戦中には出ません**
   - ボス戦の間は海底が低くなり、追い立てられて地形に潰される事故が起きにくくなっています
   - ボスごとに固有の攻撃があります
     - **カニ**: 泡を5方向に吐きます
     - **シャコ**: 溜めてから正面へ**シャコパンチ**（衝撃波の帯）を放ちます。溜め中は打突腕のまわりが光るので、そのあいだに高さをずらして避けます
     - **幽霊船の主**（巨大タコ）: 海底から**触腕を複数本同時に突き上げて**叩きつけてきます（突き上げてくる位置は事前に光る影で予告されます）。ときおり墨も吐きます
     - **ダイオウイカ**: 触腕を1本伸ばして掴みかかってきます（ステージ5では強化版が再戦相手になり、弾数・触腕の間隔が厳しくなります）
     - **ゴブリンシャーク**（ステージ5・最終ボス）: 狙いを定めてから画面を横断する噛みつき突進をしてきます。突進時は特徴的な顎が飛び出します。溜め中は安全地帯ができるので、そこで避けます
10. **ステージ4・5の潜航パート**: 大穴に差しかかると横スクロールが止まり、縦スクロールで海底の縦穴を潜っていきます
   - 左右が岩壁になり、ぶつかるとダメージを受けます。自機は画面の左右いっぱいに動けます
   - 弾は真下に向かって発射され、下から浮上してくる敵と撃ち合います
   - 潜るほど画面が暗くなり、HUDに現在の深度（DEPTH）が表示されます
   - 深度2000mまで潜ると縦穴を抜けて海底に到達し、**再び横スクロールに戻ります**（「SEA FLOOR」バナー）。深海なので画面は暗いままです
   - 深海の横スクロール区間では画面上部にも岩の天井があり、ぶつかるとダメージを受けます（海底とあわせて上下から挟まれる構造）
   - 横スクロールに戻って少し進むと、ボスが通常どおり画面後方から現れます
   - **ステージ5**はボスが強化版ダイオウイカを倒すと引き続き**ゴブリンシャークとの連戦（NEXT BOSS）**になります
11. 全5ステージあり、ボスを倒すごとに次のステージへ進みます（シャコ → カニ → 幽霊船の主 → ダイオウイカ → 強化ダイオウイカ＋ゴブリンシャーク）。ステージが切り替わると「STAGE X」のバナーが表示され、敵の撃破数・火山や渦・残骸・潜航の進行もステージごとにリセットされます。最終ステージの2体のボスを両方倒すと全クリアで、エンディングに入ります
    - エンディングでは自機が海面へ浮上していき、SCORE / TIME / 撃破数 / コンティニュー使用回数の戦績が表示されます
    - 演出を飛ばしてしまわないよう、しばらく経ってからタップでタイトルに戻れます
12. ライフが0になっても **コンティニューが2回まで** できます。画面タップで再開でき、残り回数はHUDに表示されます
    - **ボス戦で力尽きた場合**: そのボス戦から再開します（ボスのHPは全回復）
    - **それ以外で力尽きた場合**: そのステージの最初から再開します
    - コンティニューを使い切ってライフが0になるとゲームオーバー。画面タップで最初からリスタートできます
    - 再開時はライフが3に戻り、アイテムの効果（弾種・護衛機など）は失われます。スコアは引き継がれます
13. プレイ中は画面右上のボタン（PキーまたはEscキーでも可）でポーズできます。ポーズ中は敵や弾の動きが止まり、同じボタンで再開、RESTARTボタンで最初からやり直せます
14. 効果音が鳴ります。ポーズボタンの左のスピーカーボタン（Mキーでも可）でミュートを切り替えられます
    - 発射・敵の撃破・被弾・アイテム取得・バリア消滅・ボス出現/撃破・ステージ切替・ゲームオーバー・クリアに音が付いています
    - 音源ファイルは使わず Web Audio API で合成しているため、追加のアセットは不要です
    - スマホの自動再生制限のため、**最初の操作（タップやキー入力）までは音が鳴りません**
15. ベストスコアがブラウザに保存されます（`localStorage`）。タイトル・ゲームオーバー・エンディングに表示され、記録を更新するとプレイ中のHUDにも「NEW RECORD」が出ます

## デバッグモード

URLに `?debug=1` を付けて開くと、開発用のデバッグモードが有効になります（付けない通常プレイには一切影響しません）。

画面下部の操作バー右側に以下のボタンが表示されます。

- **STAGE ▶** — 次のステージへ即座に進む（最終ステージなら全クリア扱い）
- **BOSS** — 現在のステージのボスをその場で出現させる
- **MUTEKI** — 無敵のON/OFF切り替え（ONの間は被弾してもライフが減らない）

PCではキーボードでも操作できます: `N` = ステージスキップ、`B` = ボス出現、`I` = 無敵切り替え。

## 構成

- `index.html` — キャンバスとビューポート設定
- `game.js` — ゲームロジック一式（入力・敵・弾・当たり判定・描画）
- `version.js` — バージョン番号定義。PRの作成・更新のたびに GitHub Actions（`.github/workflows/version-bump.yml`）が自動で書き換える自動生成ファイルなので、手動編集しない

ビルド不要。`index.html` を開くだけで動作します。
